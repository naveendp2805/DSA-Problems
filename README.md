## ⚙️ PushMyCode

I use the **PushMyCode** VS Code extension to simplify the process of uploading solutions to this repository.

The workflow is:

```text
Solve Problem
     ↓
Submit Solution
     ↓
PushMyCode
     ↓
Git Repository
     ↓
Organized Problem Solutions
```

This allows me to focus more on solving problems while keeping my GitHub repository updated automatically.
